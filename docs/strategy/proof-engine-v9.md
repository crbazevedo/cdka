## Strategic decision

A one-step sign code is insufficient evidence that knowledge survives its future uses. The primitive for the next test is a **physical continuation plan**, including later reactions to signals and the memory state needed to keep that plan selected.

Work backwards from the desired two-epoch survival value, keeping the v6 physical kernel fixed. Enumerate every admissible causal continuation; preserve exactly the distinctions needed to choose among them; prove whether that choice can be updated using actual available signals. Do not supply a designer belief or an erased observation at runtime.

## Minimum toolkit, separated by purpose

**Algebra:** substochastic kernels, alpha vectors, positive live measures, max-sum gap, intersection of optimal continuation sets. These objects preserve task consequences rather than reconstructing the entire hidden state.

**Geometry:** upper hull of affine continuation profiles on the binary health-prior interval. Exact intersections produce decision boundaries; endpoints certify the entire interval. A linear sufficient statistic's dimension is not a physical bit budget.

**Optimization:** enumerate diagnostic partitions to optimize K code states. Selecting no more than K executable plans and assigning each signal to its best selected plan is an equivalent finite portfolio problem under the uncoupled decoder assumption. Shared truth-table cost or circuit constraints require a joint feasible mapping, not separate row choices.

**Recursive implementability:** current code, physical action and newly observed signal must uniquely determine the next code. A policy tree's hidden pointer counts as memory; the initial diagnostic cannot be reintroduced for free.

**Analysis/calculus:** the upper envelope is piecewise affine; derivatives change when the active continuation changes. A fixed flagged-erasure parameter has slope V_constant−V_code only when its event and physical effect are identical across branches. Generalized v8 noisy-driver formulas must not be replaced by that simple scaling.

**Verification:** exact Fraction algebra -> raw three-cell oracle -> all labeled encoders -> update-conflict witness -> common-policy library restriction -> browser fixtures. Tests do not prove novelty.

## Decisions from this increment

1. Do not optimize the present decision and use its label as a presumed universal memory state.
2. Do not infer that longer survival objectives always need more memory. Preserving a growing family of tasks is different from replacing the optimized horizon.
3. Small nonzero exact loss is not automatically worth a physical memory expansion. Report the value-capacity frontier and the missing cost of hardware.
4. Preserve counterfactual knowledge and decision sufficiency as separate notions: all continuations may have different predicted values even when the same plan is optimal.
5. A reference planner may use Y/history to calculate a benchmark; deployed controllers must obey the smaller physical interface. Include all new observations and action/resource traces, but no unpriced extra history.

## Refined next steps — no new branch proliferation

**R11, next minimal statement:** solve the tradeoff between diagnostic-code capacity and continued maintenance decisions when code transport/health evolves. Use a fixed finite observation tree and a library of actual update circuits. Seek the smallest update witness needed to preserve a chosen regret tolerance, not a general free posterior.

A truth-table library restriction can remove the benefit of a third code even when memory is available. Find a strict realization gap and a minimal resource certificate for closing it.

**Shared gate:** derive a necessary/sufficient relation between code states, allowable update rules and a joint controller library. Start with two epochs and the known kernel; expand only after a certificate that is not merely a standard unconstrained POMDP solution. Use MILP/SAT/inductive FSC synthesis only when independent enumeration fails to scale.

**Pause feature growth:** the scoped results here are useful but substantively covered by known compression/control ideas. The next increment must compare its exact statement to Poupart–Boutilier, approximate information states and finite-controller synthesis before adding new noise mechanisms.
