# Reachable diagnosis: the next integrated R11/R14 result

4 November 2026. Parent: maintenance-access commit `61e25cc53d3aaaf37eecc1bde0cb9cf9e9821836`.

## Purpose and resolution

The maintenance-access result characterized the distinctions required by a new
physical capability over arbitrary admissible initial laws. Its approximation
certificate covered one pair. This increment replaces that comparison boundary
with a paid acquisition process, a whole reachable preparation class, and exact
uniform complete-plan guarantees. It reuses the same NAND voter and D/R/M kernels.

The fixed source H is acquired once through a noisy sensor. Its shared output is
written three times, followed by the inherited health transition. All histories
of a fixed D/R length are generated from this one protocol. The continuation
controller receives no history label. The sensor is a priced stochastic primitive;
its circuit has not been synthesized from NANDs. Fixed routing and phase control
remain the common ideal infrastructure declared in the parent contract.

The core contribution is one pipeline:

1. Generate preparations with physically explicit acquisition and update prices.
2. Compile full physical continuation responses using the inherited kernels.
3. Restrict responses to an analytically proved reachable contrast domain.
4. Build correlated response/regret certificates for complete common programs.
5. Check fidelity floors and relative loss limits on the SAME executable program.
6. Produce a witnessing history and competitor when a requested guarantee fails.

No new physical-selector family is opened. Only R11/R14 remain active.

The four-dimensional input domain is invariant under D/R for all history lengths.
It need not remain invariant after maintenance. Full backward response propagation
precedes restriction. The failed QKA maintenance quotient is retained as a negative
fixture so that compression cannot silently erase the new health/port dependence.

The new domain result explains why the old arbitrary pair is not a witness for
this acquisition protocol: the reachable class already has enough distinctions in
the old response interface. This is a productive restriction of the earlier claim.
It also yields an implemented speed improvement without inventing another plant.

## Uniform decision contract

For V[h,p], the exact worst regret of a complete common program p over the convex
hull is max_h(max_q V[h,q]−V[h,p]). The worst case is attained at an actual generated
history. No assumption that all hull mixtures are physically prepared is needed.

The certificate binds rational values, ordered identities and the physical contract.
It supplies extrema and matching witnesses, regret bounds, a minimax lower witness
for every candidate, and an attaining common program. Checking performs finite
inequality/identity scans, without discovering an optimum again.

In the principal h2/K4 fixture there are4 histories and96 programs. DRDDM is the
unique minimax program although no individual history chooses it. The conjunction
regret≤0.003 and fidelity≥0.85 is impossible in this library; reducing the fidelity
floor to0.84 admits exactly DRDDM. Maximizing worst fidelity instead chooses DDDDM.
The library contains deterministic complete schedules with the inherited stochastic
internal maintenance trigger. It does not exhaust every physically constructible
adaptive or randomized controller.

## Findings and dead ends preserved

- Free centers of response intervals need not be physical preparation laws.
- Marginal envelopes from different histories can invent regret; use correlated
  plan differences within the same history.
- Pairwise optimal-plan compatibility and shared first actions are insufficient.
- A single sensor output must remain a shared cause of all three writes. Replacing
  it by three independent readings changes both information and price.
- Worsening the sensor shrinks regret while reducing fidelity. Keep an absolute
  floor alongside a relative loss tolerance.
- Optional work selects immediate readout I in the principal physical regime.
  The nontrivial compromise requires the stated mandatory workload.
- The symmetric boundary is not a valid Markov quotient through maintenance.
- The empirical speedup prices encoding and compilation; cache bytes are serialized
  query storage, not total resident memory or a physical-memory claim.

## Cost ledger and evidence

The physical resource box reserves acquisition, all preparations, a complete
continuation and terminal readout before outcomes. Every history/program pair fits
it componentwise; actual use remains available separately. Service is prepaid in
both internal branches. There is no scalar energy conversion or free readable
posterior.

The exact benchmark compares cached backward responses under32,16,8 and4 coordinate
evaluators. It records preparation encoding, compilation, query batches, certificate
construction/checking, rational bit lengths and serialized sizes. The four-coordinate
method saves work on this instance; all methods return the same6144 fractions.

The regression fixtures from maintenance-access remain in CI. New checks cover raw
joint acquisition and updates, the384 principal responses, the input-domain inverse
certificates, strict impossibilities and parameter-wide sensor identities.

## Next narrow gate

The experiment still builds2^h preparation histories and(K+2)2^K complete programs.
The next algorithmic gate is to avoid constructing the full response matrix when
proving a common-program guarantee. Candidate mechanisms are shared-prefix
propagation and certified bounds on correlated differences over residual program
families. Their cost must include discovery, output witnesses, rational arithmetic
and repeated use, and be measured against the present four-coordinate evaluator.

Exit criterion: an exact or tolerance-qualified certificate that prunes a family
before enumerating its members, with a demonstrated total-cost advantage on a
declared family, or a recorded obstruction explaining why the envelope is too loose.
Do not enlarge the physical grammar to obtain an easier demonstration.
