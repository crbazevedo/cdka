# Uniform interfaces over reachable preparations and one common complete plan

**Scientific status:** exact finite-dimensional identities, constructive rational
certificates, and counterexamples delimiting their physical interpretation.
This is the next R11/R14 use of the maintenance response compiler. The new
object is a class of reachable preparations evaluated against a common finite
library of complete physical plans, rather than one selected pair of laws.

The implementation is [`cdka/reachable_interfaces.py`](../../cdka/reachable_interfaces.py).
It receives a physically checked response table. Its certificate establishes
uniform prediction error, exact deterministic minimax regret, absolute value
guarantees, and compatibility of complete plans. It does not itself establish
the physical reachability or resource feasibility of that input table.

## 1. Physical and informational contract

Let `mu_1,...,mu_m` be probability laws on one finite physical state space.
Each law must be generated by a declared acquisition operation and a legal
preparation history. The experiment must verify the initial law, the
acquisition channel, all update kernels, and the resource cost of each path.
Histories compared at one decision boundary must have compatible phase,
remaining capabilities, and resource declarations.

Let `P={p_1,...,p_k}` be a finite family of **complete plans**, each feasible
from every preparation under the same declared resource constraints. A plan
may include already implemented stochastic routing, such as the faulty
maintenance voter. A plan may only branch on the physical observations
explicitly available in its implementation. An evaluator label identifying
the preparation history is not thereby available to that plan.

For a terminal success event, let `a_p(x)` be the probability of success when
plan `p` starts in state `x`. This already integrates all internal physical
randomness. The exact response table is

\[
V_{ip}=\mu_i a_p.
\]

The results below also hold for bounded real-valued rewards. Probability and
resource validity are additional obligations of the physical experiment.
The comparator and the common controller must use the same declared plan
family `P`; a more capable comparator requires a different contract.

Define the evaluator domain

\[
\mathcal C=\operatorname{conv}\{\mu_1,\ldots,\mu_m\}.
\]

Some mixtures in `C` may not be attainable by the physical preparation
protocol. Convexification does not grant free randomization, historical
memory, or access to a posterior distribution. For the worst-case objectives
proved below, an extremum is attained by an input generator itself. Thus the
same extrema hold on the finite reachable family and on its convex hull,
without requiring every mixture to be physically reachable.

## 2. Reusing the existing compiler with a hidden target bit

Suppose a hidden target `H` is constant and the physical update `K_w` acts
only on `x=(Z,bits)`, with the same kernel for `H=0` and `H=1`. Let `mu_0`
and `mu_1` be nonnegative submeasures over `x`, representing the two target
values jointly. Let `g(x)` be the probability that the actual terminal voter
outputs one.

The probability that the voter equals `H` is

\[
\begin{aligned}
V(w)
&=\mu_0K_w(\mathbf 1-g)+\mu_1K_wg\\
&=\mu_0K_w\mathbf 1+(\mu_1-\mu_0)K_wg.
\end{aligned}
\]

For a legal mass-preserving word, `K_w 1=1`, giving

\[
\boxed{V(w)=\operatorname{mass}(\mu_0)
                    +(\mu_1-\mu_0)K_wg.}
\]

Consequently the old response basis and maintenance extension can be reused
on the **signed contrast** `delta=mu_1-mu_0`. If `F_r` is an existing response
basis for remaining maintenance resource `r`, a sufficient evaluator
signature is

\[
\bigl(\operatorname{mass}(\mu_0),\ \delta F_r\bigr).
\]

The existing identities `K F_r=F_r B_K` update the contrast coordinates.
For the resource-consuming maintenance call, `M F_0=F_1 C` gives
`delta M F_0=(delta F_1) C`. The one-call grammar and its certificate are
therefore reused without materializing a doubled transition matrix for
`(H,x)`.

This gives a sufficient representation of `d_r+1` coordinates when `F_r`
has `d_r` columns. It does not assert minimality for a restricted reachable
family, nor does it reuse the old numerical dimensions unchanged after
changing the target event. Known normalization or a fixed target prior may
supply constants separately.

For substochastic or inadmissible words, the surviving-zero-mass term
`mu_0 K_w 1` must be retained. Replacing it by the initial mass would count
failed or unavailable trajectories as successful zeros. The implementation's
`contrast_value` supports this general form through `mass_response=K_w 1`.
The contrast is an evaluator quantity; it is not a physical probability law
or an additional readable register.

## 3. Exact response envelopes over the whole class

For each complete plan define

\[
L_p=\min_i V_{ip},\qquad U_p=\max_i V_{ip}.
\]

**Proposition 1 — attaining envelopes.** For every `mu` in `C`,

\[
L_p\leq \mu a_p\leq U_p.
\]

Both endpoints are attained by listed reachable preparations.

**Proof.** Write `mu=sum_i lambda_i mu_i` with nonnegative coefficients
summing to one. Then `mu a_p=sum_i lambda_i V_ip` is a convex combination
of values in `[L_p,U_p]`. The finite minimum and maximum have attaining
indices. QED.

**Proposition 2 — best arbitrary common response vector.** Among vectors
`c in R^k` assigning the same prediction to every preparation, the smallest
uniform absolute error is

\[
\boxed{\varepsilon_*=
       \frac12\max_p(U_p-L_p).}
\]

The coordinatewise midpoint `c_p=(L_p+U_p)/2` attains this bound.

**Proof.** An error bound `epsilon` requires both
`|L_p-c_p|<=epsilon` and `|U_p-c_p|<=epsilon`. The triangle inequality gives
`U_p-L_p<=2 epsilon` for every `p`. The midpoint is at most half the interval
width from every response in that interval, and an interval with maximum
width attains the bound. QED.

### A common response vector need not be a common law

With two preparation laws, their response midpoint is the response of their
average law. That property does not extend to arbitrary finite classes.

Consider three laws concentrated on three different states and the three
state-indicator queries. Their response rows are `e_1,e_2,e_3`. Every query
has envelope `[0,1]`, so the best free center is `(1/2,1/2,1/2)` with radius
`1/2`. This vector has total mass `3/2`; no probability law has that response.

The uniform mixture has response `(1/3,1/3,1/3)` and radius `2/3`. It is
optimal among probability-law centers in this example: some coordinate of
any law is at most `1/3`, and the corresponding vertex is at distance at
least `2/3`. This example needs no linear programming argument.

In general the compiler reports the response of the **uniform mean law**,

\[
\bar\mu=\frac1m\sum_i\mu_i,
\qquad
\bar v_p=\frac1m\sum_i V_{ip},
\]

and certifies its actual error
`max_{i,p}|V_ip-bar v_p|`. It makes no claim that this center is optimal
among all law centers or that preparing `bar mu` is physically feasible.
Using the free midpoint as the state of a dynamical probability model
would require additional consistency constraints.

## 4. Exact worst-case regret of one common complete plan

Let

\[
b_i=\max_{q\in P}V_{iq}
\]

be the best value for generator `i` when an informed benchmark may choose
its complete plan specifically for that generator. This is a benchmark;
the common physical controller does not receive `i`.

For a fixed common plan `p`, define regret at a law `mu` by

\[
\operatorname{Regret}(\mu,p)
=\max_{q\in P}\mu a_q-\mu a_p.
\]

**Proposition 3 — exact robust regret.**

\[
\boxed{
\sup_{\mu\in\mathcal C}\operatorname{Regret}(\mu,p)
=R_p:=\max_i(b_i-V_{ip}).
}
\]

The supremum is attained by a reachable generator and a complete comparator
plan. Hence

\[
\boxed{R_* = \min_{p\in P} R_p}
\]

is the exact minimax regret of choosing one common plan from `P`.

**Proof.** The difference against a fixed comparator is linear in `mu`.
Since `P` is finite,

\[
\begin{aligned}
\sup_{\mu\in\mathcal C}\max_q\mu(a_q-a_p)
&=\max_q\max_i\mu_i(a_q-a_p)\\
&=\max_i\left(\max_qV_{iq}-V_{ip}\right).
\end{aligned}
\]

Finite maxima supply an attaining pair `(i,q)`. Taking the finite minimum
over the chosen common plan proves the second identity. QED.

For a mixture, the best comparator value is `max_q sum_i lambda_i V_iq`.
It need not equal `sum_i lambda_i b_i`. The proof does not grant a hidden
mixture-component oracle to the comparator at a mixed law.

The optimization concerns one fixed choice from `P`. A randomized mixture
of complete plans can have a different minimax optimum and would require
its own implementation, costs, and certificate. Internal stochasticity
already represented by each physical plan remains included in `V`.

### Compatibility is a joint property of complete plans

**Corollary.** A common optimal complete plan exists precisely when

\[
\bigcap_i\operatorname{argmax}_{p\in P}V_{ip}\ne\varnothing.
\]

Equivalently, some `R_p=0` and therefore `R_*=0`.

Pairwise compatibility does not suffice. For response rows

| Preparation | A | B | C |
|---|---:|---:|---:|
| 1 | 1 | 1 | 0 |
| 2 | 0 | 1 | 1 |
| 3 | 1 | 0 | 1 |

every pair of preparations shares an optimal plan, while the three-way
intersection is empty. Each common plan has worst-case regret one.

Agreement on the first action also does not suffice. Two complete plans
`D,R` and `D,M` may have response rows `(0.9,0.1)` and `(0.1,0.9)`. Both
start with D, but their required continuations disagree and every common
complete plan has regret `0.8`. Selecting a suffix using a hidden history
would introduce an observation and decision capability absent from the
declared plan library.

### Regret must preserve the same-history dependence

Separate response envelopes cannot in general give exact regret. Suppose
plan `pi` has values `(0.1,0.9)` over two histories, while alternative `a`
has values `(0,0.8)`. Plan `pi` dominates `a` at each history, so its regret
is zero. The envelope comparison `U_a-L_pi=0.8-0.1=0.7` combines different
histories. It is a conservative bound, not an attained regret.

The certificate uses `V_iq-V_ip` at the **same** preparation index. It
retains that dependence even when reporting scalar extrema separately.

If an arbitrary common predictor approximates all plan values with error
at most `epsilon`, maximizing that predictor yields regret at most
`2 epsilon`. The exact table certificate can be sharper; response error
and control regret are distinct criteria.

## 5. Absolute success and regret are separate requirements

The worst absolute value of a plan is the same `L_p` already certified by
the response envelope. The maximin success level is

\[
V_{\rm robust}=\max_{p\in P}L_p.
\]

Minimizing regret and maximizing absolute worst-case success can select
different plans. For example:

| Preparation | A | B | C |
|---|---:|---:|---:|
| 1 | 0.9 | 0.6 | 1 |
| 2 | 0.5 | 0.6 | 0.1 |
| Worst absolute value | 0.5 | 0.6 | 0.1 |
| Worst regret | 0.1 | 0.4 | 0.5 |

A is the minimax-regret plan even though it is optimal at neither input
preparation. B is the maximin-value plan. A compromise over a reachable
class therefore need not be one of the generator-specific optima.

For a regret allowance `delta` and an absolute success floor `tau`, the
exact admissible set is

\[
\boxed{\mathcal P_{\delta,\tau}
=\{p\in P:R_p\leq\delta\ \text{and}\ L_p\geq\tau\}.}
\]

Both conditions must hold for the **same** complete plan. In the table
above, `delta=0.2` and `tau=0.55` admit no plan, even though a plan meeting
each individual requirement exists. The helper `admissible_plans` checks
the conjunction by scanning the certified per-plan bounds.

## 6. A single shared noisy sensor has an exact attenuation law

Assume a uniform hidden bit `H`, one acquisition error
`E~Bernoulli(eta)` independent of `H`, and one shared sensor value
`Y=H xor E`. The acquisition
may copy `Y` into several noisy physical cells, but it does not acquire an
independent sensor observation for each copy. The initial substrate is
independent of `(H,E)`, and the random seeds for writes, updates and repairs
are independent of `(H,E)`. Their physical effects may depend on the current
physical state. Future dynamics and plans access `Y` and that physical state
but never `H` or `E` directly. In particular, the substrate is not a second
channel carrying information about `H`. Keep the acquisition costs,
remaining resources and plan library fixed as `eta` varies.

Since `H` is uniform, `Y` is uniform and independent of `E`. Conditional on
`Y`, the subsequent terminal output `O` is independent of `E`. For every
preparation history and legal mass-preserving plan, let `V_0` be the
success probability with a perfect acquisition bit. Then

\[
\begin{aligned}
V_\eta
&=(1-\eta)\Pr(O=Y)+\eta\Pr(O\ne Y)\\
&=\eta+(1-2\eta)V_0\\
&=\frac12+(1-2\eta)\left(V_0-\frac12\right).
\end{aligned}
\]

For `0<=eta<1/2`, the affine multiplier is positive. Therefore:

- Individual optimal-plan sets, the minimax-regret plans, and the
  maximin-value plans retain their ordering.
- Every response width and free-center error radius scales by `1-2 eta`.
- Every regret `R_p`, including the optimum `R_*`, scales by `1-2 eta`.
- Absolute success values move toward `1/2`.

At `eta=1/2`, every success probability is `1/2`: all regrets and response
widths vanish because the acquired signal carries no target information.
This is why a regret-only gate can reward an uninformative preparation.
The joint condition `R_p<=delta` and `L_p>=tau` keeps the absolute task
requirement explicit.

The lemma requires the single shared acquisition, a uniform target prior,
the stated independence, and mass-preserving complete plans. If failure
mass is discarded, the general expression uses the survival probability
as well; if the sensor hardware or admissible plans change with `eta`, the
ordering statement requires a new comparison.

## 7. Constructive certificate and independent checking

The compiler supplies the following exact rational data:

1. The lower and upper response bound for each plan, with a preparation
   attaining each endpoint.
2. The free midpoint, its radius, and a plan attaining the maximum width.
3. The uniform mean-law response, its actual error radius, and an attaining
   preparation/plan pair.
4. Each preparation's optimum, with an attaining complete plan.
5. Each plan's exact worst-case regret, with an attaining preparation and
   comparator plan at that same preparation.
6. A minimax-regret plan, a maximin-value plan, and the complete set of
   plans simultaneously optimal for all preparations.

The checker verifies all table entries against the claimed upper and lower
bounds and checks every attaining equality. It verifies that the selected
minimax value equals the chosen plan's regret and is no larger than the
attaining lower bound for every other candidate. Similarly, it checks the
maximin value against all certified minima. No optimizer is called by the
checker. Tests explicitly disable the generator's argmin and argmax helpers
while verifying a JSON-roundtripped certificate.

A SHA-256 binding covers the exact rational table, ordered preparation and
plan labels, schema, and physical contract metadata. The physical experiment
must place its acquisition law, budgets, permitted observations, plan
grammar, horizon, and inherited-kernel identity in that contract.

The certificate is conditional on the physical validity and completeness
of the supplied table. Checking all allowed complete plans is a separate
grammar obligation. A digest does not prove a kernel correct, a path
reachable, or an observation physically accessible.

### API and storage

```python
certificate = compile_reachable_interface(
    values,
    preparation_labels=histories,
    plan_labels=complete_plans,
    contract=physical_contract,
)
verify_reachable_interface(
    certificate, values,
    preparation_labels=histories,
    plan_labels=complete_plans,
    contract=physical_contract,
)
allowed = admissible_plans(
    certificate, maximum_regret=Fraction(1, 100),
    minimum_value=Fraction(3, 4),
)
```

`prediction.lower` and `prediction.lower_witnesses` are the per-plan minimum
absolute values and their attaining histories. The decision block refers
to those same certified extrema for its maximin guarantee; it does not
store a second copy. All witness indices refer to the ordered input labels.
`admissible_plans` is a query over an already verified certificate.

## 8. Computational scope and next obligation

Given an `m by k` exact response table, compilation and checking each require
`O(mk)` rational arithmetic/comparison operations. The certificate contains
`O(m+k)` rational entries and witness indices in addition to the externally
supplied table. Numerator and denominator bit lengths, digest serialization,
and construction of the physical table remain real costs.

The independent checker supplies an auditable proof path, not an asymptotic
speedup over these finite scans. The signed-contrast lemma reuses the prior
response compiler and avoids constructing a doubled transition matrix; it
does not remove the cost of generating histories or complete plans. Those
families can still grow exponentially with a freely enlarged horizon.

The next compiler obligation is to discover useful preparation relations
and plan reductions while preserving these same bounds and attaining
witnesses. In particular, a proposed grouping must retain one common
complete feasible plan under the chosen regret and absolute-success gates.
An independent table row and comparator plan violating the gate provide a
concrete refutation.
