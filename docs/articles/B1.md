# B1 — Quantas distinções são necessárias para agir?

**Status científico:** Baseline conhecido · prova exata  
**Tipo:** Demonstração

> Quantas mensagens internas são suficientes para escolher alguma ação segura em qualquer estado possível?

## Intuição

Conhecer o mundo inteiro pode ser desnecessário. Estados distintos só precisam gerar mensagens diferentes se não houver uma mesma ação aceitável para eles.

## Motivação

A teoria da informação quantifica incerteza. Para controle, a pergunta relevante é quantas distinções alteram a escolha de ação. Sem essa separação, confundimos capacidade preditiva com conhecimento necessário para uma tarefa.

## Definições mínimas

| Conceito | Significado |
|---|---|
| Estado w | Uma condição possível do sistema ou ambiente. |
| Ação a | Uma intervenção fisicamente admissível. |
| Relação de viabilidade R(w,a) | Verdadeira quando a ação a satisfaz o critério de segurança no estado w. |
| Código de decisão | Mapa estado → mensagem interna → ação. Não exige prever todas as alternativas. |

## Formulação

```text
W_a = {w : R(w,a)=1}
N_min = min{|B| : B ⊆ A e ⋃(a∈B) W_a = W}
Bits fixos = ⌈log₂ N_min⌉
```

## Exemplo

Três situações possuem ações seguras {1,2}, {2,3} e {1,3}. Cada par compartilha uma ação, mas nenhuma ação serve para as três. A estrutura de compatibilidade precisa representar conjuntos, não apenas pares.

## Resultado / hipótese

O número mínimo de códigos é exatamente o tamanho da menor cobertura de estados por ações seguras. É um resultado conhecido, não um novo teorema. O número de bits de armazenamento não deve ser confundido com informação mútua média.

## Por que importa para o CDKA?

B1 fornece a ponte entre a estrutura causal das ações possíveis e o custo de memória para decisões. T1 altera essa estrutura através de um parâmetro físico; T2 a relaciona a probabilidades de falha.

## O que habilita em seguida?

Uma versão dinâmica em que os conjuntos de ações viáveis mudem com atratores, recursos e sensores; depois, buscar limites informacionais para decisões sequenciais.

## Limites e possíveis falsificações

Pressupõe observação perfeita na codificação, uma ação por decisão, zero erro e conjuntos finitos. Não estabelece intencionalidade ou autonomia.
