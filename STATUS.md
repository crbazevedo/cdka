## Executed gate: a present action is not a sufficient continuation interface

1. **Same physical dynamics:** all 64 two-epoch physical continuations of the v6 kernel are enumerated. Hidden health remains inaccessible at runtime; the controller reads only a finite diagnostic code, physical syndrome/resource and declared clock. Acquisition costs are common/sunk at the initial comparison boundary. Retained code and installed decoder library are explicit assumptions.
2. **Exact loss criterion:** signals may share a code without decision-value loss iff their sets of optimal COMPLETE continuations intersect. Sharing only the current optimal action is insufficient. This is classical max-sum/Bayes reasoning, not a new general compression theorem.
3. **Strict finite example:** equal-weight diagnostic healthy probabilities (.01,.5,.99) require two code states for a one-step optimum and three for two steps. Two signals both choose service now, but require different actions after the same next unanimous observation. Values with 1,2,3 code states are .8091779607700227, .8204089133546236 and .8206900304121558.
4. **Magnitude:** the third diagnostic state improves survival by only .0281117058 percentage point. Exact sufficiency does not establish a worthwhile physical investment.
5. **Nonmonotone horizon:** at probabilities (.15,.5,.85), the exact code requirement is 2 for one epoch and 1 for two. Replacing the objective/horizon differs from preserving an expanded family of all previous tasks. Sensor garbling does not improve attainable value.
6. **Recursive physical update:** a code update must be a function of the current code, actual action and new readable signal. A finite congruence witness rejects recovery of distinctions erased before an identical new observation.
7. **Loss localization:** the Bellman-deficit sum under actual unnormalized alive occupancy equals the compression loss. The best two-code example has zero initial-action loss; all loss occurs in the second decision.
8. **Decoder constraints:** extra code states cannot implement an absent syndrome-contingent circuit. A restricted library removes the gain of the third code. Flagged erasure has a separate affine calibration; it is not the harmful-driver architecture of v8.
